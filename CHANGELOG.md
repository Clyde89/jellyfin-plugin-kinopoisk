# Changelog

## [10.11.0.0]

Подготовлен первый самостоятельный релиз форка для Jellyfin 10.11.x.

### Добавлено

- Добавлена строгая идентификация фильмов и сериалов по Kinopoisk ID, IMDb ID, названию, году и типу.
- Добавлен фильтрованный ручной поиск через окно «Идентифицировать».
- Добавлены повторные попытки временных ошибок, ограничение частоты физических запросов и учёт `Retry-After`.
- Добавлены раздельное кэширование, отрицательное кэширование и single-flight.
- Добавлен долговременный дисковый кэш ответов API с ограничением размера и резервным использованием устаревших данных при недоступности сервиса.
- Добавлен локальный бинарный кэш постеров, фонов, логотипов, кадров и изображений персон с поддержкой `ETag`, `Last-Modified`, атомарных записей, ротации и резервного использования устаревших файлов.
- Добавлены контроль квоты API и диагностические показатели запросов, ответов API и файлов изображений на стандартной странице настроек.
- Добавлены независимые выключатели метаданных фильмов, сериалов, сезонов, эпизодов, персон, трейлеров и изображений.
- Добавлен приоритетный отбор трейлеров КиноПоиска для штатного интерфейса Jellyfin с дедупликацией, канонизацией YouTube-ссылок и ограничением количества роликов.
- Добавлены настраиваемые приоритеты официальных и русскоязычных трейлеров, включение тизеров, дополнительных роликов и подписи источника.
- Добавлен выбор источников пользовательского рейтинга и рейтинга критиков.
- Добавлены точные прокатные даты с долговременным кэшированием.
- Добавлены продолжительность, домашняя страница КиноПоиска, краткое описание как резерв, статус сериала и диапазон лет.
- Добавлена расширенная загрузка постеров, обложек, прозрачных логотипов, фонов, кадров, скриншотов и промоматериалов.
- Добавлены удалённый поиск и расширенные метаданные персон.
- Добавлены метаданные сезонов и эпизодов.
- Добавлена поддержка многосерийных файлов.
- Добавлен отдельный клиент связей сиквелов, приквелов и ремейков с повторными попытками, ограничением частоты и безопасной обработкой отсутствующих данных.
- Добавлены оперативный и долговременный кэши связей фильмов, single-flight и резерв устаревших данных.
- Добавлен детерминированный read-only планировщик локальных франшиз.
- Добавлен сервис предварительного просмотра франшиз со статистикой обработки и продолжением работы после единичной ошибки API.
- Добавлена автоматическая сборка, тестирование и публикация через GitHub Actions.
- Добавлена установка и обновление через собственный `manifest.json`.

### Исправлено

- Исключён автоматический выбор первого неоднозначного результата.
- Исправлено распознавание фильмов, сериалов, мини-сериалов и видео.
- Исправлено сохранение Kinopoisk ID после автоматического сопоставления.
- Исправлен разбор дат сезонов, эпизодов и проката.
- Исправлена шкала рейтинга критиков: десятибалльные значения КиноПоиска преобразованы в процентную шкалу Jellyfin.
- Исправлена нормализация возрастного рейтинга.
- Исправлено восстановление сгенерированных моделей API из долговременного JSON-кэша.
- Унифицирована десериализация связей фильмов с основным API-клиентом для устойчивости к неточностям опубликованной OpenAPI-схемы.
- Сохранена совместимость прежних конструкторов поставщиков метаданных и изображений.
- Исключён вывод содержимого ошибочных ответов API в журнал.
- Исключено долговременное и бинарное кэширование трейлеров.
- Исключена передача источников `KINOPOISK_WIDGET`, `YANDEX_DISK` и неизвестных сайтов штатному плееру как ложных прямых видеопотоков.

### Безопасность

- Удалён встроенный API-токен из конфигурации по умолчанию.
- Добавлен регрессионный тест отсутствия встроенного токена.
- Исключён вывод API-токена в журналы и диагностические показатели.
- Добавлена проверка допустимых HTTP- и HTTPS-ссылок перед передачей в Jellyfin и загрузкой изображения.
- Добавлена строгая проверка домена, схемы и идентификатора YouTube-ролика перед добавлением трейлера в карточку Jellyfin.
- Добавлена проверка MIME-типа `image/*` и максимального размера одного кэшируемого изображения.
- Добавлены SHA-256-имена файлов кэша без раскрытия исходных URL.
- Добавлена гарантия read-only режима фундамента франшиз: коллекции Jellyfin не создаются, не переименовываются и не изменяются.
- Обновлены тестовые зависимости `Microsoft.Extensions`.
