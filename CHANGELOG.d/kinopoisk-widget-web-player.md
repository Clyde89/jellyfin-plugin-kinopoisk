## Добавлено

- Добавлен клиентский веб-плеер трейлеров `KINOPOISK_WIDGET` с полноэкранным iframe, выбором нескольких роликов, закрытием по Escape и открытием в отдельной вкладке.
- Добавлен собственный автономный загрузчик Jellyfin Web без обязательного JavaScript Injector.
- Добавлена сборка встроенных клиентских модулей в единый файл `kinopoisk-web-client.js`.
- Добавлено идемпотентное подключение веб-клиента к `index.html` через управляемые маркеры и версию по SHA-256.
- Добавлена необязательная миграция старых регистраций КиноПоиска через публичный API JavaScript Injector, когда сторонний плагин уже установлен.
- Добавлена диагностика успешной, недоступной и ошибочной установки клиентской интеграции.
- Добавлена потокобезопасная фиксация состояния автономного веб-клиента.

## Надёжность

- Исходный `index.html` сохраняется отдельно до первой установки автономного клиента.
- Перед каждым фактическим изменением создаётся транзакционная резервная копия `index.html` и предыдущего клиентского файла.
- Для резервной копии создаются `manifest.json` и исполняемый `rollback.sh`.
- После записи проверяются SHA-256 клиентского файла, точное содержимое `index.html` и парность управляемых маркеров.
- При частичной ошибке исходные файлы автоматически восстанавливаются в рамках текущего запуска.
- Повторный запуск не переписывает уже актуальные файлы и не создаёт лишнюю резервную копию.

## Исправлено

- Исправлена ошибка Jellyfin Web «Не найден проигрыватель для запрошенных медиаданных» для трейлеров КиноПоиска, представленных iframe-виджетами.
- Добавлена строгая проверка допустимых доменов и обязательный HTTPS для внешних трейлеров.
- Сохранён штатный обработчик Jellyfin для фильмов без `KINOPOISK_WIDGET`.
- Удалена обязательная зависимость клиентских функций КиноПоиска от JavaScript Injector.

## Проверено

- Проверено наличие встроенного JavaScript-ресурса, перехват кнопки трейлера, безопасная загрузка карточки, iframe-разрешения, защита внешних ссылок и отсутствие секретных заголовков.
- Проверены идемпотентная установка управляемого блока, удаление блока, отказ при повреждённых маркерах и стабильный расчёт SHA-256.
- Проверено отсутствие ссылки на сборку JavaScript Injector в зависимостях DLL КиноПоиска.
