## Добавлено

- Добавлен клиентский веб-плеер трейлеров `KINOPOISK_WIDGET` с полноэкранным iframe, выбором нескольких роликов, закрытием по Escape и открытием в отдельной вкладке.
- Добавлен собственный автономный загрузчик Jellyfin Web без обязательного JavaScript Injector.
- Добавлена сборка встроенных клиентских модулей непосредственно внутри DLL плагина.
- Добавлен анонимный endpoint `Kinopoisk/WebClient.js`, выдающий объединённый JavaScript bundle без API-токена и пользовательских данных.
- Добавлено идемпотентное подключение endpoint к `index.html` через управляемые маркеры и версию по SHA-256.
- Добавлена поддержка условных HTTP-запросов по ETag и длительного immutable-кэширования только для URL с корректной версией bundle.
- Добавлен внешний режим `index.html` для защищённых контейнеров: установщик формирует помеченный управляемый блок, а плагин проверяет его без попытки записи.
- Добавлена необязательная миграция старых регистраций КиноПоиска через публичный API JavaScript Injector, когда сторонний плагин уже установлен.
- Добавлена диагностика успешной, недоступной и ошибочной установки клиентской интеграции.
- Добавлена потокобезопасная фиксация состояния автономного веб-клиента.

## Надёжность

- Исходный `index.html` сохраняется отдельно до первой установки автономного клиента.
- Перед каждым фактическим изменением создаётся транзакционная резервная копия `index.html`.
- Для резервной копии создаются `manifest.json` и исполняемый `rollback.sh`.
- После записи проверяются точное содержимое `index.html`, версия bundle и парность управляемых маркеров.
- При частичной ошибке исходный `index.html` автоматически восстанавливается в рамках текущего запуска.
- Повторный запуск не переписывает уже актуальный файл и не создаёт лишнюю резервную копию.
- Для защищённых контейнеров с `read_only: true` поддерживается точечное read-only bind-монтирование внешне управляемого `index.html`; корневой слой контейнера и сам файл остаются неизменяемыми.
- Отдельный writable-каталог или JavaScript-файл в Jellyfin Web не требуется.

## Исправлено

- Исправлена ошибка Jellyfin Web «Не найден проигрыватель для запрошенных медиаданных» для трейлеров КиноПоиска, представленных iframe-виджетами.
- Добавлена строгая проверка допустимых доменов и обязательный HTTPS для внешних трейлеров.
- Сохранён штатный обработчик Jellyfin для фильмов без `KINOPOISK_WIDGET`.
- Удалена обязательная зависимость клиентских функций КиноПоиска от JavaScript Injector.
- Устранена несовместимость автономного клиента с защищённым корневым файловым слоем Jellyfin: JavaScript больше не записывается в каталог Jellyfin Web.

## Проверено

- Проверено наличие всех встроенных JavaScript-ресурсов, перехват кнопки трейлера, безопасная загрузка карточки, iframe-разрешения, защита внешних ссылок и отсутствие секретных заголовков.
- Проверены идемпотентная установка управляемого блока, внешний read-only режим, удаление блока, отказ при повреждённых маркерах и Base Path-совместимый относительный URL.
- Проверены MIME-тип, ETag, `nosniff`, условный ответ `304 Not Modified` и политика кэширования endpoint.
- Проверено отсутствие ссылки на сборку JavaScript Injector в зависимостях DLL КиноПоиска.
