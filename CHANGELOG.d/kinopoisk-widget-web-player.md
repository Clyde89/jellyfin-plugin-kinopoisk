## Добавлено

- Добавлен клиентский веб-плеер трейлеров `KINOPOISK_WIDGET` с полноэкранным iframe, выбором нескольких роликов, закрытием по Escape и открытием в отдельной вкладке.
- Добавлена программная регистрация веб-плеера через JavaScript Injector без compile-time зависимости от стороннего плагина.
- Добавлена диагностика успешной, недоступной и ошибочной регистрации клиентской интеграции.
- Добавлена потокобезопасная фиксация состояния клиентской интеграции.

## Исправлено

- Исправлена ошибка Jellyfin Web «Не найден проигрыватель для запрошенных медиаданных» для трейлеров КиноПоиска, представленных iframe-виджетами.
- Добавлена строгая проверка допустимых доменов и обязательный HTTPS для внешних трейлеров.
- Сохранен штатный обработчик Jellyfin для фильмов без `KINOPOISK_WIDGET`.

## Проверено

- Проверено наличие встроенного JavaScript-ресурса, перехват кнопки трейлера, безопасная загрузка карточки, iframe-разрешения, защита внешних ссылок и отсутствие секретных заголовков.
