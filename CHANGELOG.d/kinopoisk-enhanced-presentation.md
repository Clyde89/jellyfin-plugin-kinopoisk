## Безопасность

- API-токен КиноПоиска не передаётся в клиентский JavaScript и не включается в URL.
- Внешние ссылки и изображения ограничены разрешёнными HTTPS-доменами.
- Пользовательский и внешний текст выведен через `textContent`, без выполнения HTML из API.
- Факты со спойлерами скрыты до явного действия пользователя.
- Рецензии не загружаются при активном скрытии отзывов через Spoiler Guard.
- Локализация тегов не изменяет `ProviderIds`, исходные значения тегов и поисковые URL Jellyfin.
- Временно разрешённый TMDB ID не записывается в метаданные Jellyfin и не изменяет поставщиков библиотеки.
- Запрос TMDB выполняется только через локальный авторизованный proxy Jellyfin Enhanced.

## Ограничения

- Категории `Кино`, `Цифра` и `Носитель` требуют установленного Jellyfin Enhanced, действующего IMDb ID и успешного сопоставления с TMDB.
- При отсутствии данных TMDB цифровой или физический релиз не синтезируется.
- Первая страница рецензий расходует один запрос при первом открытии карточки после истечения дискового кэша.
- Каждая дополнительная страница рецензий расходует один запрос после истечения дискового кэша.
- Похожие фильмы КиноПоиска расходуют один запрос после истечения серверного кэша.
- Визуальная локализация применяется только к тегам, уже предоставленным Jellyfin или подключённым источником.
- Мост Jellyfin Elsewhere требует включённых TMDB и Elsewhere в Jellyfin Enhanced и действующего IMDb ID.
- Расширенная подборка требует активной интеграции Seerr в Jellyfin Enhanced.
- Расширенная карточка предназначена для Jellyfin Web и клиентов, использующих его webview.
