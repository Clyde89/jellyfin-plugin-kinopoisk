## Добавлено

- Добавлена расширенная карточка КиноПоиска в Jellyfin Web.
- Добавлены отдельные рейтинги КиноПоиска, IMDb, российских и мировых критиков с количеством голосов.
- Добавлены подписанные даты `Кино`, `Цифра` и `Носитель` с указанием страны и источника.
- Добавлен резервный вывод основных дат КиноПоиска при отсутствии TMDB ID.
- Добавлено окно `Все даты релиза`, объединяющее прокатные данные КиноПоиска и категории релизов TMDB из Jellyfin Enhanced.
- Добавлены основные даты `Мировая премьера` и `Премьера в России` без дублирования одинакового начала проката.
- Добавлены расширенные профессии участников, включая операторов, композиторов, монтажёров, художников и продюсеров.
- Добавлено пошаговое раскрытие длинных списков участников по десять записей.
- Добавлены связанные фильмы, сиквелы, приквелы и ремейки.
- Добавлены лениво загружаемые разделы фактов, бюджета и сборов, наград и номинаций.
- Добавлен локальный авторизованный API расширенной карточки без передачи токена КиноПоиска браузеру.
- Добавлено двенадцатичасовое кэширование дополнительных разделов и тридцатиминутное кэширование пустых результатов.
- Добавлена регистрация клиентской карточки через JavaScript Injector.

## Исправлено

- Исправлены неоднозначные подписи прокатных дат: страна включена в название премьеры.
- Удалены дублирующие кнопки КиноПоиска и IMDb из заголовка расширенной карточки.
- Исправлено отображение HTML-разметки в фактах КиноПоиска.
- Выполнено декодирование HTML-сущностей и сохранены читаемые границы абзацев.
- Удалены исполняемые блоки `script`, `style`, `template` и `noscript` до передачи текста браузеру.

## Безопасность

- API-токен КиноПоиска не передаётся в клиентский JavaScript и не включается в URL.
- Внешние ссылки и изображения ограничены разрешёнными HTTPS-доменами.
- Пользовательский и внешний текст выведен через `textContent`, без выполнения HTML из API.
- Факты со спойлерами скрыты до явного действия пользователя.

## Ограничения

- Категории `Кино`, `Цифра` и `Носитель` требуют установленного Jellyfin Enhanced и доступного TMDB ID.
- При отсутствии TMDB ID показаны только подтверждённые даты КиноПоиска без синтеза цифрового или физического релиза.
- Дополнительные разделы расходуют по одному запросу квоты КиноПоиска только при первом открытии раздела после истечения серверного кэша.
- Расширенная карточка предназначена для Jellyfin Web и клиентов, использующих его webview.
