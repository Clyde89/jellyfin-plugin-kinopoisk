## Исправлено

- Исправлена десериализация прокатных дат, в которых API возвращает пустой `subType`; восстановлено применение точной мировой премьеры.
- Исправлена классификация успешного HTTP-ответа с ошибкой разбора: локальная ошибка десериализации больше не обозначается как ошибка API со статусом 200.
- Добавлена поддержка трейлеров `KINOPOISK_WIDGET` и совместимых ссылок Яндекс Диска с проверкой допустимых доменов и переводом на HTTPS.
- Добавлена структурированная диагностика полученных, выбранных и отклонённых трейлеров по источникам.
- Исправлено назначение `coverUrl`: горизонтальная обложка отнесена к фоновым изображениям, а не к основным постерам.
- Исправлено назначение кадров: `STILL` отнесён к фонам, `SCREENSHOT` и `SHOOTING` — к эскизам Jellyfin.
- Добавлена ограниченная пагинация изображений с соблюдением лимитов Jellyfin и API.
- Добавлена структурированная диагностика загрузки каждого типа и итогового отбора изображений.
- Исправлено сопоставление профессии `OPERATOR`: оператор больше не отображается вторым режиссёром.
- Обновлён endpoint связей на `/api/v2.2/films/{id}/relations`; сохранена совместимость объектного и устаревшего массивного формата ответа.
- Добавлено локальное обновление состояния поставщика раз в 60 секунд только при открытой и видимой странице настроек; внешняя квота КиноПоиска не расходуется.

## Проверено

- Добавлены регрессионные тесты пустого подтипа проката, профессии оператора, источников трейлеров, форматов связей и локального обновления состояния.
