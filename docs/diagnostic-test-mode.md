# Диагностический тестовый режим КиноПоиска

## Назначение

Диагностическая сессия использована для контролируемой проверки поставщика на тестовом экземпляре Jellyfin. Глобальный уровень журналирования Jellyfin не изменён.

## Безопасность

- API-токен и заголовки авторизации не записаны.
- Query-параметры URL удалены перед записью.
- Сообщения и значения областей видимости ограничены по длине.
- Исключения записаны без полного stack trace.
- Ошибка диагностической записи не влияет на поставщика метаданных.

## Уровни

- `Basic` — информационные сообщения, предупреждения и ошибки.
- `Detailed` — добавлены существующие сообщения `Debug`; уровень рекомендован для первичного тестирования.
- `Trace` — добавлены трассировочные сообщения; уровень использован только для короткой воспроизводимой проверки.

## Ограничения

- Продолжительность сессии ограничена диапазоном от 1 до 24 часов.
- Размер одного файла ограничен диапазоном от 5 до 200 МБ.
- Количество сохраняемых файлов ограничено диапазоном от 1 до 20.
- После истечения срока новая запись автоматически прекращена.

## Расположение

Файлы сохранены в каталоге данных плагина:

```text
diagnostics/kinopoisk-diagnostic-<session-id>.jsonl
```

На `media-core` фактический путь определяется поиском после запуска сессии:

```bash
find /srv/media-core/appdata/jellyfin \
  -type f -name 'kinopoisk-diagnostic-*.jsonl' -print
```

## Порядок тестирования

1. Открыта страница `КиноПоиск — диагностика`.
2. Выбран уровень `Подробный`.
3. Установлена продолжительность 6 часов.
4. Начата новая сессия.
5. Зафиксированы Session ID и время завершения.
6. Выполнено обновление тестовой библиотеки.
7. Диагностический файл скопирован без изменения исходника.
8. Сессия остановлена после завершения проверки.

Apply-задача и write-режим франшиз не входят в диагностическую проверку.
