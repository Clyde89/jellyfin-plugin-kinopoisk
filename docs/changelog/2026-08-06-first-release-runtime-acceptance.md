- Использован Jellyfin Server 10.11.11.
- Использован Compose-проект `media-core-jellyfin`.
- Сохранён `read_only: true`.
- Использован отдельный каталог плагина `КиноПоиск_10.11.0.5`.
- Сохранена XML-конфигурация плагина.

## Подтверждённые результаты

- Выполнена транзакционная установка с резервной копией и самостоятельным `rollback.sh`.
- Подтверждено состояние Jellyfin `healthy` после пересоздания только сервиса Jellyfin.
- Подтверждены установленные DLL, `meta.json`, API Jellyfin и read-only bind mount управляемого `index.html`.
- Подтверждены MIME-тип, `ETag`, `304 Not Modified`, `nosniff` и состав `Kinopoisk/WebClient.js`.
- Подтверждена неизменность `jellyfin-egress-proxy`.
- Подтверждено отсутствие автоматического запуска Preview и Apply.
- Подтверждено стабильное появление блока «Похожие и рекомендации» при SPA-переходах без обновления страницы.
- Подтверждено сохранение карточек КиноПоиска, вкладки TMDB, сопоставления Seerr и действий запроса.
