# КиноПоиск для Jellyfin

[![Проверка сборки](https://github.com/Clyde89/jellyfin-plugin-kinopoisk/actions/workflows/ci.yml/badge.svg?branch=develop)](https://github.com/Clyde89/jellyfin-plugin-kinopoisk/actions/workflows/ci.yml)

[![Лицензия GPL-3.0](https://img.shields.io/github/license/Clyde89/jellyfin-plugin-kinopoisk)](LICENSE)

Описания, постеры, рейтинги, трейлеры и рекомендации КиноПоиска — в вашей медиатеке Jellyfin.

Узнавайте больше о любимом кино, находите похожие фильмы и сохраняйте интересное на потом. Доступные фильмы можно запустить прямо из рекомендаций, а ещё не скачанные — добавить в личный список «Хочу посмотреть».

Плагин загружает сведения о фильмах, сериалах, сезонах, эпизодах и персонах через [Kinopoisk Unofficial API](https://kinopoiskapiunofficial.tech/). Основные возможности работают самостоятельно; Seerr и Jellyfin Enhanced подключаются по желанию.

> [!IMPORTANT]
> Проект является неофициальным и не связан с Яндексом, КиноПоиском или командой Jellyfin.

## О проекте

Проект продолжает разработку [LinFor/jellyfin-plugin-kinopoisk](https://github.com/LinFor/jellyfin-plugin-kinopoisk) с сохранением истории авторства и лицензии исходного плагина.

В форке реализованы:

- безопасная идентификация фильмов и сериалов без случайного выбора неоднозначного результата;
- расширенное заполнение стандартных метаданных Jellyfin;
- устойчивое взаимодействие с API, многоуровневое кэширование и контроль квоты;
- дополнительные блоки карточки Jellyfin Web;
- рекомендации КиноПоиска, воспроизведение из карточек и личный список желаемого;
- необязательные интеграции с Seerr и Jellyfin Enhanced;
- установка и обновление через собственный каталог плагинов Jellyfin.

Первым опубликованным релизом форка стала версия `10.11.0.5`. Актуальная стабильная версия указана в значке «Последний релиз» в начале страницы.

## Совместимость

| Версия плагина | Jellyfin Server | .NET | Статус |
|---|---|---|---|
| `10.11.0.11` | `10.11.11` | `9.0` | Совместимая версия для Jellyfin 10.11 |
| `12.1.0.6` | `12.1` | `10.0` | Автономные рекомендации, личное желаемое и интеграции |

Ветка `12.1.0.x` предназначена для Jellyfin 12.1 и требует ABI не ниже `12.1.0.0`. Для Jellyfin `10.11.x` в каталоге сохранена версия `10.11.0.11`.

Метаданные доступны клиентам Jellyfin. Расширенные карточки, рекомендации, личное желаемое и дополнительные окна интерфейса работают в **Jellyfin Web** и клиентах на основе совместимого WebView. Нативные приложения могут не отображать эти расширения.

При переходе с Jellyfin 10.11 на 12.1 сохраняются настройки плагина и привязки к фильмам. Перед обновлением самого сервера необходима полная резервная копия конфигурации, базы данных и данных плагина. Для отката после миграции базы потребуется восстановить эту копию. Подробнее — в [руководстве по переходу на Jellyfin 12.1](docs/native-trailer-bridge.md#перенос-на-jellyfin-121).

## Автономная работа и интеграции

Плагин самостоятельно загружает данные КиноПоиска, дополняет карточки, показывает похожие фильмы и сохраняет личное желаемое. Для этих возможностей не требуется устанавливать Seerr или Jellyfin Enhanced. Получение данных КиноПоиска требует персонального ключа Kinopoisk Unofficial API.

| Возможность | Самостоятельная работа | При подключении Seerr |
|---|---|---|
| Метаданные, изображения и трейлеры КиноПоиска | Да | Сохраняются |
| Похожие фильмы КиноПоиска для выбранного фильма | Да | Сохраняются |
| Сведения о фильме и личный список желаемого | Да | Сохраняются |
| Воспроизведение и продолжение просмотра из своей медиатеки | Да | Сохраняются |
| Дополнительные подборки The Movie Database | — | Да |
| Запросы фильмов и сезонов, квоты и статусы заявок | — | Да |

**Seerr** можно подключить напрямую из настроек плагина. **Jellyfin Enhanced** остаётся необязательной совместимой интеграцией: поддерживаются автоматическое обнаружение Enhanced и использование его подключения к Seerr.

Вы сами выбираете, пользоваться только возможностями КиноПоиска или дополнить их запросами через Seerr.

## Возможности

### Безопасная идентификация

- Приоритет ранее сохранённого Kinopoisk ID.
- Поддержка идентификаторов `kp-12345` и `kp12345` в имени файла или каталога.
- Поиск по IMDb ID, русскому, английскому и оригинальному названию.
- Учёт года выпуска и типа контента: фильмы, сериалы и мини-сериалы различаются при поиске.
- Проверка полной карточки перед сохранением найденного идентификатора.
- Ручной поиск через окно «Идентифицировать».

При неоднозначном результате плагин не выбирает первый попавшийся фильм. Явно указанный Kinopoisk ID помогает точно связать файл с нужной карточкой.

### Метаданные фильмов и сериалов

- Название, оригинальное название, описание и слоган.
- Год, точная дата премьеры, продолжительность, статус и диапазон лет сериала.
- Жанры, страны производства и возрастной рейтинг.
- Рейтинги КиноПоиска, IMDb, российских и мировых критиков.
- Выбор источников пользовательского рейтинга и рейтинга критиков Jellyfin.
- Актёры и съёмочная группа.
- Домашняя страница и ссылка на КиноПоиск.
- Краткое описание как резерв при отсутствии полного.

### Изображения

Доступные категории изображений Kinopoisk Unofficial API:

- постеры;
- обложки;
- фоновые изображения;
- промоматериалы;
- концепт-арты;
- кадры;
- скриншоты;
- съёмочные материалы;
- обои.

Изображения распределяются по подходящим категориям Jellyfin, повторяющиеся адреса исключаются. Если отдельная категория недоступна, остальные продолжают загружаться.

### Персоны

- Поиск персон с приоритетом точного совпадения русского или английского имени.
- Исключение повторяющихся результатов по Kinopoisk ID.
- Русское и оригинальное имя.
- Даты и места рождения и смерти.
- Профессия, биографические факты, фотография и ссылка на карточку КиноПоиска.

### Сезоны и эпизоды

- Названия `Сезон N` и `Специальные материалы`.
- Дата начала и год сезона.
- Количество эпизодов в описании сезона.
- Русское и оригинальное названия эпизода, описание, дата выхода и год.
- Поддержка многосерийных файлов с объединением названий и описаний нескольких эпизодов.

### Трейлеры

- Приоритет официальных и русскоязычных роликов.
- Отдельные настройки тизеров и дополнительных материалов.
- Настраиваемое максимальное количество роликов и исключение повторов.
- Поддержка YouTube и виджета КиноПоиска; ссылки Яндекс Диска открываются отдельно.
- Подготовка трейлеров КиноПоиска для штатного плеера Jellyfin.

Трейлеры КиноПоиска сохраняются на сервере в MP4-кэш без перекодирования. При первом запуске может потребоваться дождаться подготовки; последующие просмотры используют сохранённый файл. Готовые трейлеры остаются привязаны к своим фильмам.

Размер кэша и срок хранения настраиваются. Плагин удаляет давно не используемые ролики и не создаёт дополнительные файлы в папках медиатеки. Подготовку трейлеров можно включить для всех клиентов Jellyfin или только для Android TV.

YouTube доступен как отдельный настраиваемый резервный источник и не входит в серверный MP4-кэш. Подробнее — в [руководстве по нативным трейлерам](docs/native-trailer-bridge.md).

### Расширенная карточка Jellyfin Web

Карточка фильма или сериала может включать:

- подтверждённые даты премьер;
- факты, бюджет и сборы;
- награды и рецензии;
- похожие фильмы КиноПоиска;
- дополнительные подборки The Movie Database при подключении Seerr;
- сведения о наличии фильма и состоянии запроса Seerr;
- воспроизведение, избранное и сохранение в желаемое.

Постеры загружаются через сервер Jellyfin. Дополнительные разделы подхватываются при переходах между фильмами и оформлены в привычном стиле Jellyfin.

В рекомендациях КиноПоиска показываются похожие фильмы для открытой карточки. Нажатие на постер, название или значок информации открывает сведения о выбранном фильме. При подключении Seerr в этом же окне доступны действия для запроса.

Карточки используют штатные эффекты наведения и подсветку действий. Стрелки карусели появляются, когда все карточки не помещаются на экране, и учитывают начало и конец списка.

### Запросы через Seerr

Запрашивайте недостающие фильмы и сезоны, не покидая Jellyfin.

- Прямое подключение Seerr из настроек плагина или использование интеграции Jellyfin Enhanced.
- Проверка введённых адреса и API-ключа до сохранения настроек.
- Подтверждение запроса перед отправкой, выбор сезонов и отображение пользовательской квоты.
- Статусы заявок с автоматическим обновлением карточек и открытого окна.
- Кнопка «Открыть в Seerr» с выбором удобного адреса.

Для прямого подключения укажите адрес Seerr, доступный серверу Jellyfin, и API-ключ из общих настроек Seerr. Для запросов пользователь Jellyfin должен быть связан с учётной записью Seerr; используются права и квота этой учётной записи.

Адрес для открытия Seerr в браузере настраивается отдельно:

- **Автоматически** — адрес из настроек Seerr; если он не указан, используется адрес подключения.
- **Адрес подключения** — локальный адрес, указанный для Seerr в плагине.
- **Свой адрес** — адрес, выбранный пользователем, например внешний адрес для доступа вне дома.

Плагин передаёт подтверждённый запрос. Поиском и загрузкой управляют Seerr, Radarr и Sonarr с учётом их настроек и правил одобрения.

### Воспроизведение и желаемое

На карточках доступных фильмов и сериалов появляется штатная кнопка воспроизведения. Если просмотр уже начат, его можно продолжить с сохранённого места.

Сердечко помогает сохранить интересное:

- фильм из своей медиатеки добавляется в избранное Jellyfin;
- ещё не скачанный фильм сохраняется в личное желаемое;
- повторное нажатие снимает сохранённую отметку.

Желаемое доступно во вкладке **«Желаемое»** внутри рекомендаций и в стандартном **«Избранном»** Jellyfin Web:

- **«Готово к просмотру — фильмы»** и **«Готово к просмотру — сериалы»** — избранное из медиатеки;
- **«Хочу посмотреть»** — личный список с пояснением «Сохранено на потом, даже если фильм ещё не скачан».

Это один личный список: изменения отображаются в обоих местах. Он сохраняется на сервере между устройствами и перезапусками Jellyfin и доступен только соответствующему пользователю.

Воспроизведение и сохранение желаемого работают без Seerr и Enhanced. Сохранение сердечком не запускает загрузку: запросить фильм через подключённый Seerr можно отдельным действием с подтверждением.

### Подключение к Jellyfin Web

Дополнительные разделы подключаются автоматически после установки плагина. Отдельный JavaScript Injector, ручное изменение `index.html`, копирование скриптов и дополнительные подключения файлов не требуются.

Штатные файлы Jellyfin Web на диске остаются без изменений. Веб-интеграцию можно выключить в параметрах плагина; получение обычных метаданных настраивается отдельно.

<details>
<summary>Технические особенности веб-интеграции</summary>

Клиентский модуль `Kinopoisk/WebClient.js` встроен в плагин и подключается к ответу Jellyfin Web. Поддерживаются установки с неизменяемым корневым файловым слоем, браузерное кэширование через `ETag` и ответы `304 Not Modified`. Если подключение модуля невозможно, сервер возвращает исходную страницу Jellyfin Web.

</details>

### Надёжность API и кэширование

- Повторные попытки при временной недоступности API, сетевых ошибках и тайм-аутах.
- Учёт ограничений поставщика и пауз перед повторными запросами.
- Оперативный и дисковый кэш сведений, а также отдельный кэш изображений.
- Настраиваемые сроки хранения и пределы размера дискового кэша.
- Использование ранее сохранённых данных при временной недоступности API.
- Фоновый контроль API-ключа и квоты.

Кэш помогает быстрее открывать карточки и уменьшает число повторных обращений к поставщику.

<details>
<summary>Подробности обработки запросов и кэша</summary>

Повторные попытки предусмотрены для HTTP `408`, `429`, `500`, `502`, `503` и `504` с учётом `Retry-After`. Ошибки авторизации `401` не повторяются автоматически. Интервал между физическими запросами к API составляет не менее 200 мс.

Разделены кэши карточек, поиска, персон, изображений, сезонов, участников, связей и трейлеров. Повторные одинаковые запросы объединяются; отсутствие результата также может кэшироваться. Файлы изображений сохраняются с защитой от неполной записи, ротацией и поддержкой `ETag` и `Last-Modified`.

Содержимое ошибочных ответов API не записывается в журналы.

</details>

### Параметры и диагностика

На странице плагина доступны вкладки **«Основные параметры»** и **«Диагностика (Debug)»** с выделением выбранного раздела.

- Независимое включение фильмов, сериалов, сезонов и эпизодов, персон, трейлеров и изображений.
- Настройки рейтингов, кэшей, квоты, трейлеров и веб-интеграции.
- Подключение Seerr и выбор способа интеграции.
- Состояние поставщика, счётчики обращений и статистика кэша трейлеров.
- Диагностические сессии с автоматическим завершением и уровнями `Базовый`, `Подробный` и `Трассировка`.
- Диагностические файлы JSONL с ротацией и идентификаторами сессий и запросов для разбора проблем.

API-токен, заголовки авторизации и параметры запросов исключаются из диагностических файлов.

Подробное описание размещено в [документации диагностического режима](docs/diagnostic-test-mode.md).

### Франшизы и управляемые коллекции

Доступен предварительный просмотр франшиз по фильмам и сериалам из своей медиатеки с учётом сиквелов, приквелов и ремейков.

Предварительный просмотр формирует отчёт и не изменяет медиатеку или ручные коллекции. Автоматическое создание и изменение коллекций не включено в пользовательские возможности этой версии.

<details>
<summary>Развитие управляемых коллекций</summary>

Предусмотрены сохранение отчётов с ротацией и проверка соответствия плана перед применением. Изменения коллекций требуют актуального предварительного отчёта и отдельного ручного запуска. Пользовательские переключатели применения и автоматическое расписание пока недоступны.

</details>

## Установка через каталог Jellyfin

> [!WARNING]
> Исходный плагин и этот форк используют один идентификатор. Одновременное подключение двух репозиториев может привести к конфликту версий.

### 1. Удаление исходного репозитория

Если ранее был подключён репозиторий LinFor, откройте раздел:

```text
Панель администратора → Плагины → Репозитории
```

Удалите только запись репозитория, адрес которой содержит `LinFor/jellyfin-plugin-kinopoisk`. Официальный репозиторий Jellyfin оставьте подключённым.

Удаление адреса репозитория не удаляет установленный плагин и его конфигурацию.

### 2. Подключение репозитория форка

Добавьте запись:

| Поле | Значение |
|---|---|
| Название | `КиноПоиск — Clyde89` |
| URL | `https://raw.githubusercontent.com/Clyde89/jellyfin-plugin-kinopoisk/release/dist/manifest.json` |

### 3. Установка плагина

Откройте раздел:

```text
Панель администратора → Плагины → Каталог → Метаданные
```

Выберите плагин **КиноПоиск**, установите совместимую версию и перезапустите Jellyfin.

Дополнительные разделы Jellyfin Web подключатся автоматически. После обновления плагина при необходимости обновите страницу браузера через **Ctrl+F5**.

## Обновление

Новые стабильные версии публикуются в [GitHub Releases](https://github.com/Clyde89/jellyfin-plugin-kinopoisk/releases) и автоматически добавляются в каталог Jellyfin.

Перед обновлением сохраните резервную копию данных и настроек Jellyfin. Установите обновление из каталога плагинов и перезапустите сервер. При необходимости обновите страницу браузера через **Ctrl+F5**.

## Настройка API-токена

Для получения данных КиноПоиска нужен собственный токен [Kinopoisk Unofficial API](https://kinopoiskapiunofficial.tech/).

Откройте раздел:

```text
Панель администратора
→ Плагины
→ Мои плагины
→ КиноПоиск
→ Параметры
```

Укажите токен в поле **«Персональный API-токен»** и сохраните параметры. Новый ключ применяется сразу после сохранения.

> [!CAUTION]
> API-токен является секретом. Его публикация в исходном коде, журналах, задачах GitHub или сообщениях поддержки не допускается.

```text
Шрэк 2 (2004) [kp-5273]
```

## Разработка

<details>
<summary>Ветвление и команды для разработчиков</summary>

В проекте используется следующая модель ветвления:

| Ветка | Назначение |
|---|---|
| `master` | сохранённая база исходного проекта |
| `develop` | интеграционная ветка разработки |
| `feature/*` | функциональные изменения |
| `fix/*` | исправления |
| `release` | стабильный каталог Jellyfin |

Команды для сборки и проверки исходного кода:

```bash
dotnet restore src/Jellyfin.Plugin.Kinopoisk.sln

dotnet build \
  src/Jellyfin.Plugin.Kinopoisk.sln \
  --configuration Release \
  --no-restore

dotnet test \
  src/Jellyfin.Plugin.Kinopoisk.sln \
  --configuration Release \
  --no-build

npm ci --ignore-scripts
npm run test:web
```

Параметры публикации версии находятся в `release/version.json`. После обновления этой записи в `develop` запускается процесс выпуска; доступен и ручной запуск.

</details>
