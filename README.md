# КиноПоиск для Jellyfin

[![Проверка сборки](https://github.com/Clyde89/jellyfin-plugin-kinopoisk/actions/workflows/ci.yml/badge.svg?branch=develop)](https://github.com/Clyde89/jellyfin-plugin-kinopoisk/actions/workflows/ci.yml)
[![Последний релиз](https://img.shields.io/github/v/release/Clyde89/jellyfin-plugin-kinopoisk?display_name=tag&sort=semver)](https://github.com/Clyde89/jellyfin-plugin-kinopoisk/releases)
[![Лицензия GPL-3.0](https://img.shields.io/github/license/Clyde89/jellyfin-plugin-kinopoisk)](LICENSE)

Русскоязычный поставщик метаданных КиноПоиска для Jellyfin.

Плагин загружает сведения о фильмах, сериалах, сезонах, эпизодах и персонах через [Kinopoisk Unofficial API](https://kinopoiskapiunofficial.tech/), а также дополняет Jellyfin Web данными КиноПоиска, рекомендациями и поддерживаемыми интеграциями.

> [!IMPORTANT]
> Проект является неофициальным и не связан с Яндексом, КиноПоиском или командой Jellyfin.

## О проекте

Репозиторий продолжил разработку [LinFor/jellyfin-plugin-kinopoisk](https://github.com/LinFor/jellyfin-plugin-kinopoisk) с сохранением истории авторства и лицензии исходного проекта.

В форке реализованы:

- безопасная идентификация фильмов и сериалов без случайного выбора неоднозначного результата;
- расширенное заполнение стандартных метаданных Jellyfin;
- устойчивое взаимодействие с API, многоуровневое кэширование и контроль квоты;
- дополнительные блоки карточки Jellyfin Web;
- установка и обновление через собственный каталог плагинов Jellyfin.

Первым опубликованным релизом форка стала версия `10.11.0.5`. Актуальная стабильная версия указана в значке «Последний релиз» в начале документа.

## Совместимость

| Компонент | Поддержка |
|---|---|
| Jellyfin Server | `10.11.x` |
| Проверенная версия Jellyfin Server | `10.11.11` |
| .NET | `9.0` |
| Язык метаданных | русский |
| Категория плагина | Metadata |

Серверные метаданные доступны всем клиентам Jellyfin. Дополнительные блоки карточки поддержаны Jellyfin Web и клиентами на основе совместимого WebView; нативные клиенты могут не отображать клиентские расширения.

## Возможности

### Безопасная идентификация

- Сохранён приоритет ранее записанного Kinopoisk ID.
- Поддержаны идентификаторы `kp-12345` и `kp12345` в имени файла или каталога.
- Добавлен поиск по IMDb ID.
- Добавлено сопоставление русского, английского и оригинального названий.
- Добавлены проверки года выпуска и типа контента.
- Разделены фильмы, сериалы и мини-сериалы.
- Исключён автоматический выбор первого неоднозначного результата.
- Добавлена окончательная проверка полной карточки до сохранения автоматически найденного идентификатора.
- Расширен ручной поиск через окно «Идентифицировать».

### Метаданные фильмов и сериалов

- Загружены название, оригинальное название, описание и слоган.
- Загружены год, точная дата премьеры, продолжительность, статус и диапазон лет сериала.
- Загружены жанры, страны производства и возрастной рейтинг.
- Загружены рейтинги КиноПоиска, IMDb, российских и мировых критиков.
- Добавлен выбор источников пользовательского рейтинга и рейтинга критиков Jellyfin.
- Загружены актёры и съёмочная группа.
- Добавлены домашняя страница и внешняя ссылка на КиноПоиск.
- Добавлено краткое описание как резерв при отсутствии полного описания.

### Изображения

Поддержаны категории изображений Kinopoisk Unofficial API:

- постеры;
- обложки;
- фоновые изображения;
- промоматериалы;
- концепт-арты;
- кадры;
- скриншоты;
- съёмочные материалы;
- обои.

Добавлены сопоставление категорий с типами изображений Jellyfin, удаление дублирующихся адресов, ограниченная пагинация и независимая обработка недоступных категорий.

### Персоны

- Добавлен удалённый поиск персон.
- Добавлен приоритет точного совпадения русского или английского имени.
- Добавлена дедупликация результатов по Kinopoisk ID.
- Загружены русское и оригинальное имя.
- Загружены даты и места рождения и смерти.
- Загружены профессия, биографические факты, фотография и ссылка на карточку КиноПоиска.

### Сезоны и эпизоды

- Сформированы названия `Сезон N` и `Специальные материалы`.
- Загружены дата начала и год сезона.
- Количество эпизодов добавлено в описание сезона.
- Загружены русское и оригинальное названия эпизода, описание, дата выхода и год.
- Добавлена поддержка многосерийных файлов с объединением названий и описаний нескольких эпизодов.

### Трейлеры

- Добавлен приоритетный отбор официальных и русскоязычных роликов.
- Добавлены отдельные параметры для тизеров и дополнительных материалов.
- Ограничено максимальное количество роликов.
- Добавлены нормализация адресов и дедупликация.
- Поддержаны YouTube, виджет КиноПоиска и безопасное внешнее открытие ссылок Яндекс Диска.
- Исключена передача непрямых источников штатному плееру Jellyfin как ложных медиапотоков.

В версии `10.11.0.11` [NativeTrailerBridge](docs/native-trailer-bridge.md) распространён на все фильмы с трейлером КиноПоиска. При открытии карточки плагин быстро регистрирует штатный `LocalTrailer`, а сервер в фоне сохраняет HLS как MP4 без перекодирования. Первый запуск может дождаться этой же фоновой операции; повторные запускаются напрямую из локального файла без ffmpeg. Кэш ограничен по размеру, очищается по LRU и сроку неиспользования, не создаёт файлов в медиапапках и может применяться ко всем клиентам Jellyfin либо только к Android TV. На странице параметров доступны размер, количество файлов, попадания, промахи, записи, ошибки и ротация. YouTube остаётся управляемым клиентским резервом и в серверный MP4-кэш не входит.

### Расширенная карточка Jellyfin Web

В карточку фильма или сериала добавлены:

- подтверждённые даты премьер;
- факты, бюджет и сборы;
- награды и рецензии;
- похожие фильмы КиноПоиска;
- рекомендации The Movie Database;
- сопоставление с Seerr и состояние запроса;
- совместимость с Jellyfin Enhanced;
- защищённая серверная загрузка постеров;
- устойчивое восстановление блоков после SPA-переходов Jellyfin Web.

### Подключение к Jellyfin Web

Клиентский модуль `Kinopoisk/WebClient.js` встроен в DLL плагина. После стандартной установки из каталога Runtime Web Bootstrap подключил этот модуль к HTTP-ответу Jellyfin Web.

- Штатный `index.html` на диске не изменён.
- Отдельный JavaScript Injector, внешний файл и дополнительный bind mount не потребовались.
- Сохранена работа Jellyfin с неизменяемым корневым файловым слоем.
- Добавлены `ETag`, ответ `304 Not Modified` и корректный MIME-тип.
- При ошибке преобразования возвращён исходный HTML без нарушения загрузки Jellyfin Web.
- Веб-интеграция может быть выключена в параметрах плагина.

### Надёжность API и кэширование

- Добавлены повторные попытки при HTTP `408`, `429`, `500`, `502`, `503` и `504`.
- Добавлены повторные попытки при временных сетевых ошибках и тайм-аутах.
- Учтён заголовок `Retry-After`.
- Исключены повторные попытки при ошибке авторизации `401`.
- Ограничены физические запросы к API интервалом не менее 200 мс.
- Разделены оперативные кэши карточек, поиска, персон, изображений, сезонов, участников, связей и трейлеров.
- Добавлены отрицательное кэширование и объединение параллельных одинаковых запросов через single-flight.
- Добавлен долговременный дисковый кэш ответов с настраиваемыми сроками и пределом размера.
- Добавлен резерв устаревших данных при временной недоступности API.
- Добавлен бинарный кэш изображений с атомарной записью, ротацией, `ETag` и `Last-Modified`.
- Добавлен фоновый контроль API-ключа и квоты.
- Исключено содержимое ошибочного ответа API из журналов.

### Параметры и диагностика

Основные параметры и диагностика объединены на одной странице плагина.

- Добавлены вкладки «Основные параметры» и «Диагностика (Debug)» с явным визуальным обозначением выбранного раздела.
- Добавлены независимые выключатели фильмов, сериалов, сезонов и эпизодов, персон, трейлеров и изображений.
- Добавлены параметры кэшей, квоты, рейтингов, трейлеров и веб-интеграции, а также оперативная статистика MP4-кэша трейлеров.
- Добавлены ограниченные по времени диагностические сессии.
- Добавлены уровни `Базовый`, `Подробный` и `Трассировка`.
- Добавлены JSONL-файлы, ротация, Session ID и correlation ID.
- API-токен, заголовки авторизации и query-параметры исключены из диагностических файлов.

Подробное описание размещено в [документации диагностического режима](docs/diagnostic-test-mode.md).

### Франшизы и управляемые коллекции

- Добавлен read-only предварительный просмотр франшиз по локальным фильмам и сериалам.
- Добавлены связи сиквелов, приквелов и ремейков.
- Добавлены атомарный отчёт, ротация и отпечаток плана.
- Реализован внутренний защищённый механизм управляемых коллекций.
- Пользовательские переключатели применения скрыты до отдельной runtime-приёмки.
- Автоматическое расписание Preview и Apply не добавлено.
- Ручные коллекции не изменяются.

## Установка через каталог Jellyfin

> [!WARNING]
> Исходный плагин и этот форк используют одинаковый GUID. Одновременное подключение двух репозиториев может привести к конфликту версий.

### 1. Удаление исходного репозитория

При наличии репозитория LinFor открыт раздел:

```text
Панель администратора → Плагины → Репозитории
```

Удалена только запись репозитория, URL которой содержит `LinFor/jellyfin-plugin-kinopoisk`. Официальный репозиторий Jellyfin сохранён.

Удаление адреса репозитория не удаляет установленный плагин и его конфигурацию.

### 2. Подключение репозитория форка

Добавлена запись:

| Поле | Значение |
|---|---|
| Название | `КиноПоиск — Clyde89` |
| URL | `https://raw.githubusercontent.com/Clyde89/jellyfin-plugin-kinopoisk/release/dist/manifest.json` |

### 3. Установка плагина

Открыт раздел:

```text
Панель администратора → Плагины → Каталог → Метаданные
```

Выбран плагин **КиноПоиск**, установлена доступная версия и перезапущен Jellyfin.

Дополнительное изменение `index.html` и ручное подключение `WebClient.js` не потребовались.

## Обновление

Новые стабильные версии публикуются в [GitHub Releases](https://github.com/Clyde89/jellyfin-plugin-kinopoisk/releases) и автоматически добавляются в каталог Jellyfin.

Перед обновлением сохранены резервные копии каталога плагина и его XML-конфигурации. После установки обновления перезапущен Jellyfin.

## Настройка API-токена

Встроенный общий API-токен удалён. Для работы плагина получен собственный токен [Kinopoisk Unofficial API](https://kinopoiskapiunofficial.tech/).

Открыт раздел:

```text
Панель администратора
→ Плагины
→ Мои плагины
→ КиноПоиск
→ Параметры
```

Токен указан в поле «Персональный API-токен», после чего параметры сохранены.

> [!CAUTION]
> API-токен является секретом. Его публикация в исходном коде, журналах, задачах GitHub или сообщениях поддержки не допускается.

## Рекомендуемая структура медиатеки

Для точной привязки указан Kinopoisk ID в имени фильма или корневого каталога сериала:

```text
Шрэк 2 (2004) [kp-5273]
```

или:

```text
Шрэк 2 (2004) [kp5273]
```

Явно указанный идентификатор получил приоритет перед автоматическим поиском.

## Структура репозитория

| Путь | Назначение |
|---|---|
| `src/Jellyfin.Plugin.Kinopoisk` | исходный код плагина и клиентские модули |
| `src/Jellyfin.Plugin.Kinopoisk.Tests` | регрессионные тесты плагина |
| `src/KinopoiskUnofficialInfo.ApiClient` | клиент Kinopoisk Unofficial API |
| `src/KinopoiskUnofficialInfo.ApiClient.Tests` | тесты API-клиента и записанные ответы |
| `tests/web` | DOM-проверки карточки Jellyfin Web и SPA-переходов |
| `docs` | пользовательская документация |
| `assets` | локальные графические ресурсы проекта |
| `.github/workflows` | сборка, платформенные и runtime-проверки, публикация релиза |

Стабильный `manifest.json` хранится отдельно в ветке `release`. Скомпилированные ZIP-архивы не хранятся в `develop`; релизные пакеты опубликованы в GitHub Releases.

## Разработка

Использована следующая модель ветвления:

| Ветка | Назначение |
|---|---|
| `master` | сохранённая база исходного проекта |
| `develop` | интеграционная ветка разработки |
| `feature/*` | функциональные изменения |
| `fix/*` | исправления |
| `release` | стабильный каталог Jellyfin |

Локальная проверка выполнена командами:

```bash
dotnet restore src/Jellyfin.Plugin.Kinopoisk.sln

dotnet build \
  src/Jellyfin.Plugin.Kinopoisk.sln \
  --configuration Release \
  --no-restore

dotnet test \
  src/Jellyfin.Plugin.Kinopoisk.sln \
  --configuration Release \
  --no-build

npm ci --ignore-scripts
npm run test:web
```

## План развития

- Запланировано расширение runtime-проверок на дополнительных клиентах Jellyfin и мобильных разрешениях.
- Запланирована отдельная приёмка фактического применения управляемых коллекций до публикации пользовательских write-переключателей.
- Запланирована адаптация к новым стабильным версиям Jellyfin.
- Запланирована отдельная сетевая приёмка маршрутизации клиентского YouTube-трафика через домашний шлюз без серверного скачивания или кэширования роликов.

Автоматические операции изменения коллекций не включены без свежего совпадающего preview-отчёта и явного ручного запуска.
