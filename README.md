# КиноПоиск для Jellyfin

[![Проверка сборки](https://github.com/Clyde89/jellyfin-plugin-kinopoisk/actions/workflows/ci.yml/badge.svg?branch=develop)](https://github.com/Clyde89/jellyfin-plugin-kinopoisk/actions/workflows/ci.yml)
[![Последний релиз](https://img.shields.io/github/v/release/Clyde89/jellyfin-plugin-kinopoisk?display_name=tag&sort=semver)](https://github.com/Clyde89/jellyfin-plugin-kinopoisk/releases)
[![Лицензия GPL-3.0](https://img.shields.io/github/license/Clyde89/jellyfin-plugin-kinopoisk)](LICENSE)

Русскоязычный поставщик метаданных КиноПоиска для Jellyfin.

Плагин загружает сведения о фильмах, сериалах, сезонах, эпизодах и персонах через сервис [Kinopoisk Unofficial API](https://kinopoiskapiunofficial.tech/).

> [!IMPORTANT]
> Проект является неофициальным и не связан с Яндексом, КиноПоиском или командой Jellyfin.

## О проекте

Репозиторий является активно развиваемым форком проекта [LinFor/jellyfin-plugin-kinopoisk](https://github.com/LinFor/jellyfin-plugin-kinopoisk).

Основные направления разработки:

- безопасная идентификация фильмов и сериалов без случайного выбора неоднозначного результата;
- надёжное взаимодействие с API КиноПоиска;
- расширенное заполнение метаданных Jellyfin;
- автоматическая установка и обновление через каталог плагинов Jellyfin;
- сохранение совместимости с актуальными стабильными версиями Jellyfin.

## Совместимость

| Компонент | Поддерживаемая версия |
|---|---|
| Jellyfin Server | 10.11.x |
| .NET | 9.0 |
| Язык метаданных | русский |
| Категория плагина | Metadata |

Первая самостоятельная версия форка подготовлена под номером `10.11.0.0`.

## Возможности

### Безопасная идентификация

- Сохранён приоритет ранее записанного Kinopoisk ID.
- Поддержаны идентификаторы `kp-12345` и `kp12345` в имени файла или каталога.
- Добавлен поиск по IMDb ID.
- Добавлено сопоставление русского, английского и оригинального названия.
- Добавлена проверка года выпуска.
- Добавлено разделение фильмов, сериалов и мини-сериалов по типу.
- Исключён автоматический выбор первого неоднозначного результата.
- Добавлена окончательная проверка полной карточки перед сохранением автоматически найденного идентификатора.
- Добавлен расширенный ручной поиск через окно «Идентифицировать».

### Метаданные фильмов и сериалов

- Загружены название и оригинальное название.
- Загружены описание и слоган.
- Загружены год и дата премьеры.
- Загружены жанры и страны производства.
- Загружен возрастной рейтинг.
- Загружены рейтинги КиноПоиска и IMDb.
- Загружены оценки кинокритиков.
- Загружены актёры и съёмочная группа.
- Добавлена внешняя ссылка на КиноПоиск.
- Добавлены трейлеры из поддерживаемых Jellyfin источников.

### Изображения

Поддержаны категории изображений API КиноПоиска:

- постеры;
- обложки;
- фоновые изображения;
- промоматериалы;
- концепт-арты;
- кадры;
- скриншоты;
- съёмочные материалы;
- обои.

Добавлены сопоставление категорий с типами изображений Jellyfin, удаление дублирующихся адресов, ограничения количества результатов и независимая обработка недоступной категории.

### Персоны

- Добавлен удалённый поиск персон.
- Добавлен приоритет точного совпадения русского или английского имени.
- Добавлена дедупликация результатов по Kinopoisk ID.
- Загружены русское и оригинальное имя.
- Загружены дата и место рождения.
- Загружены дата и место смерти.
- Загружены профессия и биографические факты.
- Загружены фотография и ссылка на карточку КиноПоиска.

### Сезоны и эпизоды

Для сезонов загружены:

- локализованное название;
- дата начала;
- год;
- количество эпизодов.

Для эпизодов загружены:

- русское название;
- оригинальное название;
- описание;
- дата выхода;
- год.

Добавлена поддержка многосерийных файлов с объединением названий и описаний нескольких эпизодов.

### Надёжность API

- Добавлены повторные попытки при HTTP `408`, `429`, `500`, `502`, `503` и `504`.
- Добавлены повторные попытки при временных сетевых ошибках и тайм-аутах.
- Добавлен учёт заголовка `Retry-After`.
- Исключены повторные попытки при ошибке авторизации `401`.
- Ограничены физические запросы к API интервалом не менее 200 мс.
- Добавлено раздельное кэширование карточек, поиска, персон, изображений, сезонов, участников и трейлеров.
- Добавлено краткое отрицательное кэширование пустых результатов.
- Добавлено объединение параллельных одинаковых запросов через single-flight.
- Исключено содержимое ошибочного ответа API из журналов.

## Установка через каталог Jellyfin

> [!WARNING]
> Исходный плагин и этот форк используют одинаковый GUID. Одновременное подключение двух репозиториев не рекомендуется из-за возможного конфликта версий.

### 1. Удаление исходного репозитория

При наличии репозитория LinFor открыт раздел:

```text
Панель администратора → Плагины → Репозитории
```

Удалён исходный репозиторий КиноПоиска перед подключением репозитория этого форка.

Удаление адреса репозитория не удаляет установленный плагин и его конфигурацию.

### 2. Подключение репозитория форка

Создан новый репозиторий:

| Поле | Значение |
|---|---|
| Название | `КиноПоиск` |
| URL | `https://raw.githubusercontent.com/Clyde89/jellyfin-plugin-kinopoisk/release/dist/manifest.json` |

### 3. Установка плагина

Открыт раздел:

```text
Панель администратора → Плагины → Каталог → Метаданные
```

Выбран плагин **КиноПоиск**, установлена доступная версия и перезапущен Jellyfin.

> [!NOTE]
> До публикации первого самостоятельного релиза каталог может не содержать доступных версий.

## Обновление

Новые стабильные версии публикуются в GitHub Releases и автоматически добавляются в `manifest.json`.

После появления новой версии выполнены установка обновления и перезапуск Jellyfin.

Перед обновлением рекомендовано резервное копирование каталога плагина и его XML-конфигурации.

## Настройка API-токена

Встроенный общий API-токен удалён.

Для работы плагина требуется собственный токен [Kinopoisk Unofficial API](https://kinopoiskapiunofficial.tech/).

После получения токена открыт раздел:

```text
Панель администратора
→ Плагины
→ Мои плагины
→ КиноПоиск
→ Параметры
```

Токен указан в поле `ApiToken`, после чего конфигурация сохранена.

> [!CAUTION]
> API-токен является секретом. Его публикация в исходном коде, журналах, задачах GitHub или сообщениях поддержки не допускается.

## Рекомендуемая структура медиатеки

Для точной привязки допускается указание Kinopoisk ID в имени фильма или корневого каталога сериала:

```text
Шрэк 2 (2004) [kp-5273]
```

или:

```text
Шрэк 2 (2004) [kp5273]
```

Явное указание идентификатора имеет приоритет перед автоматическим поиском.

## Проверка качества

Разработка сопровождается автоматической сборкой и тестированием через GitHub Actions.

На момент подготовки первого самостоятельного релиза проверены:

- API-клиент;
- строгая идентификация;
- фильтрованный поиск;
- повторные попытки;
- ограничение частоты запросов;
- кэширование и single-flight;
- изображения;
- персоны;
- сезоны;
- одиночные и многосерийные эпизоды;
- отсутствие встроенного API-токена.

Выполнено более 100 автоматических тестов.

## План развития

Запланированы следующие направления:

- расширенное определение состояния сериала;
- дата завершения сериала;
- уточнение дат премьер и продолжительности;
- безопасное формирование франшиз и коллекций с предварительным просмотром;
- дополнительные параметры загрузки изображений и персон;
- расширенная диагностика API;
- улучшение страницы конфигурации;
- повышение прозрачности кэширования и повторных попыток;
- последующая адаптация к новым стабильным версиям Jellyfin.

Автоматическое создание франшиз не будет включено до появления надёжного алгоритма, исключающего ошибочное объединение ремейков, спин-оффов и связанных произведений.

## Разработка

Использована следующая модель ветвления:

| Ветка | Назначение |
|---|---|
| `master` | чистое зеркало исходного проекта |
| `develop` | интеграционная ветка разработки |
| `feature/*` | отдельные функциональные изменения |
| `fix/*` | исправления |
| `release` | стабильный каталог `manifest.json` |

Локальная проверка:

```bash
dotnet restore src/Jellyfin.Plugin.Kinopoisk/Jellyfin.Plugin.Kinopoisk.csproj

dotnet build \
  src/Jellyfin.Plugin.Kinopoisk/Jellyfin.Plugin.Kinopoisk.csproj \
  --configuration Release

dotnet test \
  src/KinopoiskUnofficialInfo.ApiClient.Tests/KinopoiskUnofficialInfo.ApiClient.Tests.csproj \
  --configuration Release

dotnet test \
  src/Jellyfin.Plugin.Kinopoisk.Tests/Jellyfin.Plugin.Kinopoisk.Tests.csproj \
  --configuration Release
```
