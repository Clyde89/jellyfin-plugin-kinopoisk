Диагностическая сессия КиноПоиска

Режим предназначен для контролируемого тестирования. Он не изменяет глобальный уровень журналирования Jellyfin, автоматически завершается и записывает только события КиноПоиска в отдельный JSONL-файл. API-токен и заголовки авторизации не сохраняются.
После сохранения новая сессия будет создана автоматически. Для принудительного начала новой сессии используйте отдельную кнопку ниже.
Для первичной проверки библиотеки рекомендуется «Подробный». «Трассировка» создаёт значительно больше записей.
После истечения указанного времени запись автоматически прекращается. Рекомендуемое значение: 6 часов.
После достижения ограничения текущий файл архивируется, а запись продолжается в новом файле. Рекомендуемое значение: 25 МБ.
Самые старые диагностические файлы удаляются автоматически. Рекомендуемое значение: 5.
