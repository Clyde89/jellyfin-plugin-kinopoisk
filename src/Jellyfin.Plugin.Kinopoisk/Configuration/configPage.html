Подключение к API

Токен выдаётся после регистрации на kinopoiskapiunofficial.tech. Токен хранится в конфигурации Jellyfin и не выводится в журнал.

Стандартные функции Jellyfin

Название, оригинальное название, описание, год, страны, жанры, возрастной рейтинг, рейтинги и идентификаторы.
Основная карточка сериала и связанные стандартные поля Jellyfin.
Названия, даты выпуска, описания и поддержка многосерийных файлов.
Актёры, режиссёры, сценаристы, продюсеры и расширенные карточки персон.
В штатный список трейлеров Jellyfin добавляются поддерживаемые ссылки, полученные через API КиноПоиска. Трейлеры не сохраняются в долговременном дисковом кэше.
Постеры, обложки, фоны, кадры, изображения со съёмок, промоматериалы, концепт-арты и скриншоты.

Кэширование API

Ответы API сохраняются в каталоге данных плагина и используются после перезапуска Jellyfin. Трейлеры исключены из дискового кэша.
При временной недоступности API или исчерпании квоты используется последний сохранённый ответ, даже если его обычный срок хранения завершён.
Рекомендуемое значение: 168 часов.
Рекомендуемое значение: 720 часов.
Увеличенное значение уменьшает расход квоты при повторной идентификации.
Пустые ответы сохраняются ненадолго, чтобы исключить циклические повторные запросы.
При превышении ограничения первыми удаляются самые старые файлы кэша.

Контроль квоты

Состояние ключа периодически проверяется без вывода токена в журнал. Полученные сведения используются для диагностики и защиты от лишних запросов.
Рекомендуемое значение: 6 часов. Сам запрос состояния ключа также учитывается внешним сервисом.
