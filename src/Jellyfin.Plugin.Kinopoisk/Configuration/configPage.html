Подключение к API

Токен выдаётся после регистрации на kinopoiskapiunofficial.tech. Токен хранится в конфигурации Jellyfin и не выводится в журнал.

Стандартные функции Jellyfin

Название, оригинальное название, описание, год, страны, жанры, возрастной рейтинг, рейтинги и идентификаторы.
Основная карточка сериала и связанные стандартные поля Jellyfin.
Названия, даты выпуска, описания и поддержка многосерийных файлов.
Актёры, режиссёры, сценаристы, продюсеры и расширенные карточки персон.
В штатный список трейлеров Jellyfin добавляются поддерживаемые ролики, полученные через API КиноПоиска. Трейлеры не сохраняются в долговременном или бинарном кэше.
Постеры, обложки, прозрачные логотипы, фоны, кадры, изображения со съёмок, промоматериалы, концепт-арты и скриншоты.

Трейлеры КиноПоиска

Внутри штатного интерфейса Jellyfin воспроизводятся только безопасно распознанные YouTube-ролики, возвращённые API КиноПоиска. Источники KINOPOISK_WIDGET и Яндекс.Диск не являются прямыми медиапотоками и не подменяются неработающими ссылками воспроизведения.
Ограничивает число роликов в стандартной карточке Jellyfin. Рекомендуемое значение: 5.
Официальные ролики поднимаются выше неофициальных, фанатских и концептуальных видео.
Русские, дублированные и озвученные ролики располагаются выше остальных при одинаковом типе видео.
Тизеры добавляются после полноценных трейлеров, если не заняли более высокий приоритет по языку и официальности.
Разрешает фрагменты, интервью, материалы со съёмок, клипы и телевизионные ролики. По умолчанию отключено, чтобы карточка не перегружалась.
К названию ролика добавляется префикс «КиноПоиск —», чтобы источник был понятен в интерфейсе Jellyfin.

Полнота стандартных метаданных

Определяет источник стандартного поля CommunityRating. Рейтинги сохраняются по десятибалльной шкале Jellyfin.
Рейтинг КиноПоиска преобразуется из десятибалльной шкалы в процентную шкалу CriticRating Jellyfin.
Выполняется дополнительный кэшируемый запрос прокатных данных. Мировая премьера имеет приоритет, затем используется кинотеатральная премьера.
Поле продолжительности заполняется из карточки КиноПоиска. После анализа локального файла Jellyfin может уточнить значение по фактическому медиапотоку.
В стандартное поле домашней страницы добавляется безопасная HTTP- или HTTPS-ссылка на карточку фильма или сериала.
Заполняются год начала, дата завершения и стандартный статус Jellyfin: ожидается, продолжается или завершён.
При отсутствии полного описания используется краткое описание КиноПоиска. Существующее полное описание не заменяется кратким.

Франшизы и связи

Текущий этап работает только в режиме предварительного просмотра. Откройте «Панель управления → Задачи по расписанию» и вручную запустите задачу «Предварительный просмотр франшиз КиноПоиска». Отчёт будет атомарно сохранён в каталоге данных плагина: reports/franchise-preview-latest.json. Коллекции Jellyfin не создаются и не изменяются.
В предварительный план включаются локальные сериалы с сохранённым Kinopoisk ID. Сезоны и эпизоды не участвуют.
Продолжения объединяются с другими локальными объектами одной связанной группы.
Предыстории объединяются с другими локальными объектами одной связанной группы.
Ремейки могут относиться к самостоятельным интерпретациям, поэтому по умолчанию исключены.
Группа с меньшим количеством объектов не включается в отчёт. Рекомендуемое значение: 2.
Добавляется к названию опорного фильма только в плане. Значение по умолчанию: « — коллекция».
Параметр принудительно включён. Плагин никогда не должен переименовывать, очищать или удалять коллекции, не имеющие собственного маркера КиноПоиска.

Кэширование ответов API

Ответы API сохраняются в каталоге данных плагина и используются после перезапуска Jellyfin. Трейлеры исключены.
При временной недоступности API или исчерпании квоты используется последний сохранённый ответ, даже если его обычный срок хранения завершён.
Рекомендуемое значение: 168 часов.
Кэшируются сведения и URL изображений, но не сами графические файлы. Рекомендуемое значение: 720 часов.
Увеличенное значение уменьшает расход квоты при повторной идентификации.
Пустые ответы сохраняются ненадолго, чтобы исключить циклические повторные запросы.
При превышении ограничения первыми удаляются самые старые записи.

Локальный кэш файлов изображений

Jellyfin сохраняет загруженные постеры, фоны, логотипы, кадры и фотографии персон в каталоге данных плагина. Повторные обращения обслуживаются локально и не нагружают удалённые CDN. Трейлеры этой функцией не затрагиваются.
Если удалённый сервер временно недоступен, Jellyfin продолжает отдавать последнюю сохранённую копию изображения.
После завершения срока выполняется условная проверка ETag или Last-Modified. При отсутствии изменений файл не скачивается повторно. Рекомендуемое значение: 30 дней.
При превышении ограничения удаляются наименее недавно использованные изображения. Рекомендуемое значение: 2048 МБ.
Слишком крупное изображение передаётся Jellyfin напрямую, но не сохраняется локально. Рекомендуемое значение: 25 МБ.

Контроль квоты

Состояние ключа периодически проверяется без вывода токена в журнал. Полученные сведения используются для диагностики и защиты от лишних запросов.
Рекомендуемое значение: 6 часов. Сам запрос состояния ключа также учитывается внешним сервисом.
